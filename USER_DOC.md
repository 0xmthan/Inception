# User documentation

## Services

| Service   | Role                                  | Access                        |
|-----------|---------------------------------------|-------------------------------|
| NGINX     | HTTPS entry point (TLS 1.2/1.3)       | https://mtaheri.42.fr (443)   |
| WordPress | The website (php-fpm)                 | through NGINX                 |
| MariaDB   | WordPress database                    | internal only                 |
| Redis     | WordPress object cache                | internal only                 |
| FTP       | File access to the WordPress files    | `ftp://localhost:21`          |
| Adminer   | Database admin UI                     | http://localhost:8081         |
| Static    | Static showcase site                  | http://localhost:8080         |
| DOOM      | Browser game                          | http://localhost:8082         |

## Start and stop

```sh
make          # build and start
make stop     # pause the containers
make start    # resume them
make down     # stop and remove the containers (data is kept)
```

## Access

- **Website:** run `make host` once, then open https://mtaheri.42.fr and accept the self-signed certificate.
- **WordPress admin panel:** https://mtaheri.42.fr/wp-admin
- **Adminer:** http://localhost:8081, server `mariadb`, database `wordpress`.

## Credentials

Usernames are in `srcs/.env`; passwords are in `secrets/` (generated by `make` if missing).

| Account          | User (`srcs/.env`) | Password                                   |
|------------------|--------------------|--------------------------------------------|
| WP admin         | `WP_ADMIN_USER`    | `WP_ADMIN_PASSWORD` in `secrets/credentials.txt` |
| WP user          | `WP_USER`          | `WP_USER_PASSWORD` in `secrets/credentials.txt`  |
| Database         | `MYSQL_USER`       | `secrets/db_password.txt`                  |
| Database root    | `root`             | `secrets/db_root_password.txt`             |
| FTP              | `FTP_USER`         | `secrets/ftp_password.txt`                 |

Never commit these files. To change a password, edit the file and run `make fclean && make` (accounts are created on first start).

## Check that it runs

```sh
make ps                            # all containers "Up", mariadb "healthy"
make logs                          # live logs of every service
curl -kI https://mtaheri.42.fr     # HTTP 200
```
